    Where do I get this file?

    This dashboard inspects existing evidence. It does not send prompts to an AI assistant.

    Option A · Import a saved chat (easier)

    1. Open a ChatGPT conversation that used web search.
    2. Use the “Watch this chat” bookmark on this page. Drag its button to your bookmarks bar, then click it inside that chat.
    3. If automatic transfer fails, click Save snapshot in the AI-tab panel, then upload the downloaded chatgpt_raw.json here. Private endpoints may change.

    A normal account data export, copied answer, share link, or screenshot is not the same input. Saved chats may omit search queries and metadata.

    Option B · Record a network response (advanced)

    Start the local recorder before sending a new web-search prompt. It requires Node.js 22+ and Chrome. Then import its JSON capture. 

    node runner/capture.mjs --provider chatgpt

    Success means an analysis opens with source evidence or a clear limitation—not just a downloaded file. No authenticated provider capture has been verified for this release.

    Advanced · Capture a live network response locally

    The hosted dashboard cannot intercept another website. The optional local utility records response bodies before a prompt is sent. It needs Node.js 22+ and Chrome, not an API key. Login is manual in a dedicated browser profile.

    1. Download or clone the repository and open a terminal in its root folder.
    2. Run the command below. Log in in the browser it opens.
    3. Enable web search, send one prompt, and wait for the answer to finish.
    4. Press Enter in the terminal. Drop the saved capture JSON above. If evidence is missing or unsupported, the import reports that rather than inventing results. 
    node runner/capture.mjs --provider chatgpt

    Other capture targets: claude, gemini, perplexity, grok. Capture targeting is not a claim that their private browser-stream formats are supported. Gemini's private batchexecute and Grok's private nested format are currently unsupported; use their documented API JSON instead. No authenticated provider capture was live-tested for this release.

    A note on what “watching” means

    The bookmark reads the current tab's saved conversation repeatedly with your own login. Switching chats in that tab changes which chat is synced. This is automatic chat sync, not a network-stream recorder. Queries or rich metadata that the site does not save cannot appear here. An answer still being generated may have incomplete evidence.

    Connection trouble? Try these quick fixes
    • Keep the local server running. Open http://localhost:8000/ or http://127.0.0.1:8000/, not the terminal's [::] bind address.
    • Allow pop-ups for the AI site. Replace the old “Send to Citation Tracker” bookmark with this new “Watch this chat” bookmark.
    • The bookmark remembers this tracker address. Re-add it if you move between localhost, 127.0.0.1, or GitHub Pages.
    • Click the bookmark again after reloading the AI page or tracker. Normal in-app new-chat navigation can stay connected.
    • If login, rate limits, browser policies, or changed private endpoints block access, the panel reports that. Stop or pause it rather than retrying repeatedly.
    • After a successful read, use Save snapshot in the AI-tab panel if automatic transfer fails. File imports and the advanced network recorder remain available on Add data.

    A simple example of the numbers

    If a response retrieves 10 sources and cites 3 of them, its matched citation rate is 30%. That describes source use—not answer quality or accuracy.

    Prefer manual import?

    What the numbers mean

    • Retrieved: present in the response's search or grounding results. This is not proof the full page was read.
    • Cited: a URL linked by structured answer citations or a resolved citation reference—not just any link in answer text.
    • Retrieved sources cited (%): retrieved-and-cited sources divided by observed retrievals. A dash means no observed denominator.
    • AI search query: a search query visible in supported tool fields. Missing query data is not zero searches.
    Technical details · Formats and evidence fields

    Supported saved response formats

    Provider format Retrieval evidence Citation evidence / limit
    ChatGPT saved chat metadata.search_result_groups Resolved inline references and content_references; active branch when available
    Claude saved chat Named web_search tool results Text-block citations; tool blocks must be included
    OpenAI Responses API web_search_call.action.sources URL annotations; request source inclusion when calling the API
    Anthropic Messages API web_search_tool_result Text-block web citations
    Gemini generateContent API Grounding chunks Grounding support indices; first candidate only, not a full search log
    Perplexity Sonar API search_results if supplied citations; citation-only when retrieval records are missing
    Grok / xAI completion API search_results if supplied citations / URL annotations; model must identify Grok or provider be explicit

    API formats are fixture-tested. That does not establish compatibility with each provider's consumer website, all API versions, or live accounts. SSE support is scoped in the capture guide. Unknown providers can use the explicit normalized schema.

    Source details, only when present

    Analysis details retain full available snippets, publication dates, attribution, channel name, followers, verification, views, likes, description, and text timecodes. Missing metadata stays missing. No transcript or extra source page is fetched. Provider-visible status labels are not hidden reasoning.

    Privacy and storage

    Imports are parsed here and normalized evidence is stored in this browser's localStorage. No analytics or API keys are used. The bookmark sends this selected conversation directly to your tracker tab; the tracker parses it locally. Hosting still makes normal asset requests; source links contact those sites. Browser storage is origin-wide, not encrypted, and not synced across devices. Export a backup before clearing it.
