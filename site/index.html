1 · One-click capture (bookmarklet)

  1. Show your bookmarks bar (Ctrl+Shift+B).
  2. Drag this button onto the bookmarks bar:
    📌 Send to Citation Tracker
  3. Open any ChatGPT or Claude chat that searched the web, then click the bookmark.
  4. This dashboard opens and the run appears automatically.

If your browser blocks the hand-off, the bookmark downloads the chat as a JSON file instead. Drop that file in box 2.

2 · Upload saved conversation files

…or paste JSON

3 · Batch automation (many prompts)

The runner/batch_runner.py script opens a logged-in browser, sends every prompt in prompts.txt to ChatGPT and Claude, waits for each answer, and saves the conversations to runner/out/. Drop that whole folder's files in box 2.

python batch_runner.py --login          # first time only: log in to both sites
python batch_runner.py                  # runs prompts.txt on chatgpt + claude

Privacy

I don't run a server, so nothing gets uploaded anywhere. Runs are saved in your browser's localStorage. The bookmarklet only reads the chat you have open, with your own login.

What doesn't work yet

  • ChatGPT doesn't save its fan-out queries in the conversation. To get them I need to capture the live stream, which is my next step.
  • These sites change their formats often. I kept the parser small so I can fix it quickly when that happens.
  • The batch runner drives a real browser on my own account, so I only use it for a handful of prompts. It won't scale as-is (captchas, terms of service).
