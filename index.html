Try the project without an account

This app inspects sources in saved AI responses. It does not ask an AI a new question or connect to provider accounts.

1. Try the guided demo

No login, API key, upload, or installation on the hosted site. Seven synthetic responses show the workflow. Saved data stays untouched.

2. Test an import

Use a bundled OpenAI example to preview one response, then choose whether to save it. No need to find a file first.

3. Bring your own file

Choose Import data, select a supported JSON/JSONL response, review the preview, and save. A copied answer or screenshot is not a supported input.

Review the original case

Two source-only extracts from the earlier supplied ChatGPT and Claude saved chats. No account tokens or complete conversations are bundled. This is prior saved-chat evidence, not a successful live-stream capture.

What the terms mean

Run
One saved response or conversation.
Retrieved
A source present in the exported search or grounding results—not proof that the full page was read.
Cited
A source linked to citation evidence in the answer.
Citation only
A citation is visible, but the response does not include its retrieval record.
Matched rate
Retrieved sources that were also cited, divided by all observed retrieved sources. A dash means the denominator is unavailable.
Fan-out query
An extra search query the provider ran. Missing query data does not mean no searches happened.
About the interview assignment

This is an evidence-review prototype, not a completed network-stream investigation. The earlier saved-chat evidence covers ChatGPT and Claude; ChatGPT live-stream fan-out extraction and rich YouTube metadata remain unverified. Additional adapters are fixture-tested, not live platform research.
