# My release notes

## My v3.1.0 beginner and evidence review update

I added a four-step, non-destructive demo, a plain-language glossary, one-click example import preview, and prior saved-case source extracts. I preserved available citation snapshot metadata and added an honest audit of the original Beyond Labs brief. I do not claim the missing live-stream research is complete.

## My v3.0.1 wording correction

I kept first-person narration in my README and documentation, and restored neutral product wording throughout the interface, error messages, and command-line output. I refreshed the documentation screenshots and updated quoted button labels to match.

## My v3.0 rebuild

I replaced the previous single-page prototype with a restrained evidence workspace, separate views, a mobile menu, theme controls, accessible native dialogs, and a source-level inspector.

I added explicit import adapters for OpenAI Responses, Anthropic Messages, Gemini grounding, Perplexity Sonar, and Grok chat-completion citations, alongside saved ChatGPT and Claude conversations. I added a normalized schema for other providers rather than claiming unverified native compatibility.

I separated my shared parser core from the browser interface, added JSONL and pasted JSON ingestion, preview-before-save behavior, safe CSV export, round-trip JSON backups, local data controls, and explicit v1 browser migration warnings.

I stopped conflating citations with retrievals. I now calculate matched citation rate only with a valid observed retrieval denominator. I keep missing queries, timestamps, and unresolved references visible.

I added synthetic examples, regression tests, a local CLI, GitHub CI checks, and first-person operational documentation.

I removed the old private-endpoint browser runner and bookmarklet from my supported v3 workflow. I use saved files rather than promising that provider authentication and private endpoints will continue working.
